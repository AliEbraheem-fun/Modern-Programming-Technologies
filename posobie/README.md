# Учебное пособие «Современные технологии программирования»

Исходники печатного издания. Собирается в PDF средствами XeLaTeX.

## Сборка

```bash
python build.py
```

Скрипт генерирует приложение с ключами к тестам, дважды прогоняет `xelatex`
(второй проход нужен для оглавления и перекрёстных ссылок) и печатает отчёт:
число страниц, ошибки LaTeX, вылеты за поля, битые ссылки и объём в печатных
листах.

Результат — `posobie.pdf`.

## Требования

| Инструмент | Назначение |
|---|---|
| XeLaTeX (MiKTeX или TeX Live) | сборка PDF, нужен именно XeLaTeX из-за кириллицы и шрифтов |
| Python 3 | вспомогательные скрипты |
| Шрифты Times New Roman, Arial, Consolas | заданы в `preamble.tex` |

Если шрифтов Consolas нет (Linux), замените в `preamble.tex` строку
`\setmonofont{Consolas}` на любой моноширинный с кириллицей, например
`\setmonofont{DejaVu Sans Mono}`.

## Структура

```
posobie.tex          главный файл: подключает всё остальное
preamble.tex         пакеты, стили, оформление по ГОСТ
SPEC.md              спецификация конверсии (для авторов глав)

front/               передний блок
  titul.tex            титульный лист
  oborot.tex           оборот титула: УДК, ББК, рецензенты, аннотация
  sokrashcheniya.tex   список сокращений
  vvedenie.tex         введение

chapters/            основной текст
  ch01.tex … ch12.tex

back/                задний блок
  zaklyuchenie.tex     заключение
  glossariy.tex        глоссарий
  literatura.tex       список литературы по ГОСТ Р 7.0.100-2018
  app_keys.tex         приложение с ключами (ГЕНЕРИРУЕТСЯ, не править)
  app_setup.tex        приложение: подготовка рабочего места

keys/                ключи к тестам по главам (chNN.json) — источник для app_keys
mmd/                 исходные mermaid-диаграммы сайта (справочно)
build/               временные файлы сборки
```

## Проверка качества

```bash
python lint.py                  # весь комплект
python lint.py chapters/ch01.tex
```

Линтер ловит остатки markdown, посторонние алфавиты, эмодзи, прямые кавычки
вместо ёлочек, ссылки на сайт и GitHub, слишком длинные строки кода и
рисунки/таблицы без ссылки в тексте.

```bash
python checkchapter.py 01
```

Собирает одну главу изолированно — быстрее, чем гонять всю книгу, когда правишь
один файл.

## Что нужно заполнить перед сдачей в издательство

В файлах `front/titul.tex` и `front/oborot.tex` помечены комментарием
`% ЗАПОЛНИТЬ` поля, которые автор и редакционно-издательский отдел заполняют сами:

- полное официальное написание имени автора и название департамента;
- индексы УДК и ББК (присваивает научная библиотека);
- авторский знак;
- **рецензенты** — с 2022 года издание без указанных рецензентов не включается
  в РИНЦ; требуется не менее двух, один из них внешний;
- номер и дата протокола заседания Учёного совета (гриф);
- ISBN (присваивает издательство);
- объём в страницах — проставляется после финальной вёрстки.

Отдельно стоит сверить выходные данные и ISBN изданий в `back/literatura.tex`
с теми, что реально используются в курсе: у переизданий они различаются.

## Диаграммы

Диаграммы нарисованы средствами LaTeX (`tikz`, `forest`, `pgfplots`), а не
вставлены картинками. Это даёт векторную графику, единый с текстом шрифт и
компактную вёрстку. Исходные mermaid-блоки с сайта лежат в `mmd/` для справки —
в сборке они не участвуют.
