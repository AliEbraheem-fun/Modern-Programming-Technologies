# Темы презентаций для 3-го модуля: Spring

Данный раздел содержит темы групповых презентаций, посвящённых фреймворку Spring и экосистеме Spring Boot. Каждая тема рассчитана на группу из 2–3 студентов.

---

## Общая информация

| Параметр | Значение |
|----------|----------|
| **Формат работы** | Групповая презентация (2–3 человека) |
| **Продолжительность выступления** | 10-15 минут |
| **Количество слайдов** | 15–25 слайдов |
| **Язык презентации** | Русский |
| **Формат файла** | PDF или PPTX |

> **Важно:** Все участники группы должны принимать участие в выступлении и быть готовы ответить на вопросы по любой части презентации.

---

## Требования к презентации

- Презентация должна содержать **примеры кода на Java/Spring Boot**, иллюстрирующие рассматриваемый механизм (аннотации, конфигурация, минимальный рабочий фрагмент)
- Рекомендуется подготовить **демонстрацию** — запущенное Spring Boot приложение или тест, показывающие обсуждаемую возможность в работе
- Необходимо объяснить, **какую проблему решает** рассматриваемый механизм и что происходило бы без него
- Все утверждения должны быть подкреплены **ссылками на официальную документацию** (docs.spring.io)

> **Внимание:** Использование мобильного телефона во время выступления, а также чтение текста со слайдов, распечаток или сторонних источников без демонстрации реального понимания материала будет приводить к **снижению оценки**. Оценивается именно владение темой: умение отвечать на вопросы, объяснять код своими словами и обосновывать решения в конкретном сценарии.

## Темы презентаций

| № | Тема | Суть и цель раскрытия темы |
|:-:|------|------|
| 1 | **Spring Core: IoC и DI простыми словами** | Что такое инверсия управления и внедрение зависимостей. Как контейнер Spring управляет бинами. Примеры `@Component`, `@Autowired`. Понять, почему Spring называют «контейнером». |
| 2 | **Жизненный цикл бина в Spring** | От создания до уничтожения. `@PostConstruct`, `@PreDestroy`, `BeanPostProcessor`. Показать, что Spring управляет объектами не хаотично, а по чётким правилам. |
| 3 | **Spring Boot: магия автоконфигурации** | Как `@SpringBootApplication` и `@EnableAutoConfiguration` избавляют от ручной настройки. Развеять миф о «магии» и показать, что это просто умный механизм. |
| 4 | **Стартеры Spring Boot: зачем они нужны** | Как один стартер подтягивает десятки зависимостей. Примеры `spring-boot-starter-web`, `spring-boot-starter-data-jpa`. Показать, как стартеры упрощают сборку проекта. |
| 5 | **Spring MVC: как обрабатывается HTTP-запрос** | Путь запроса от `DispatcherServlet` до контроллера. Роль `@Controller`, `@RestController`, `@RequestMapping`. Понять, что происходит «под капотом» веб-приложения. |
| 6 | **Валидация данных в Spring** | `@Valid`, `@NotNull`, `@Size`. Обработка ошибок валидации через `@ExceptionHandler`. Показать, как не пропустить «мусор» в API. |
| 7 | **Обработка исключений в REST API** | `@ControllerAdvice`, `@ExceptionHandler`. Единый формат ответа об ошибке. Научить делать API предсказуемым для клиента. |
| 8 | **Spring Security: аутентификация и авторизация** | Как работает цепочка фильтров. Роли, `@PreAuthorize`, JWT. Показать, как защитить приложение «из коробки». |
| 9 | **Spring Data JPA: магия репозиториев** | Как `JpaRepository` избавляет от написания SQL. Derived queries, `@Query`. Показать, как быстро делать CRUD. |
| 10 | **Проблема N+1 в Hibernate и как её решить** | Почему `JOIN FETCH` и `@EntityGraph` важны. Научить писать эффективные запросы. |
| 11 | **Транзакции в Spring: `@Transactional` и его ловушки** | Self-invocation, приватные методы, `rollbackFor`. Показать, что «магия» транзакций имеет границы. |
| 12 | **Liquibase и Flyway: миграции БД в Spring Boot** | Как управлять схемой БД через код. Показать, как избежать ручных изменений в БД. |
| 13 | **Spring AOP: сквозная логика без дублирования** | Аспекты, `@Around`, `@Before`. Пример логирования. Показать, как вынести «обвязку» из бизнес-логики. |
| 14 | **Spring AI: интеграция LLM в Java-приложение** | `ChatClient`, RAG, Tool Calling. Показать, как Java-разработчик может использовать AI без Python. |
| 15 | **Spring Cloud: микросервисы и Service Discovery** | Eureka, Config Server, API Gateway. Показать, как строить распределённые системы. |
| 16 | **Spring Kafka: асинхронная обработка сообщений** | `@KafkaListener`, `KafkaTemplate`, Outbox pattern. Научить строить событийно-ориентированные системы. |
| 17 | **Реактивное программирование в Spring: WebFlux vs MVC** | Неблокирующий ввод-вывод, `Flux`, `Mono`. Показать, когда реактивность даёт выигрыш. |
| 18 | **Spring Native и GraalVM: компиляция в нативный код** | AOT-компиляция, мгновенный старт, экономия памяти. Показать альтернативу традиционной JVM. |
| 19 | **Тестирование Spring-приложений: `@SpringBootTest`, `@WebMvcTest`, `@DataJpaTest`** | Разница между видами тестов. Mockito и `@MockBean`. Научить тестировать без запуска всего приложения. |
| 20 | **Testcontainers: интеграционные тесты с реальной БД** | Как поднять PostgreSQL в Docker для тестов. Показать, как тестировать с реальными зависимостями. |
| 21 | **Слоистая архитектура в Spring: Controller → Service → Repository** | Зачем разделять ответственность. DTO vs Entity. Научить строить поддерживаемые приложения. |
| 22 | **Spring и принципы SOLID: как не превратить проект в «спагетти»** | Примеры нарушения и соблюдения принципов. Показать, что Spring не спасёт от плохой архитектуры. |
| 23 | **Spring в корпоративной разработке: почему Java всё ещё нужна** | Экосистема, стабильность, кадры. Сравнение с Go, Python, Rust. Ответить на вопрос «зачем учить Spring в 2026 году». |

## Полезные ресурсы

### Книги

- **Spring in Action** — Craig Walls (6th Edition, Manning) — основная книга по Spring Boot, от основ до Spring Cloud и реактивного стека
- **Spring Boot: Up and Running** — Mark Heckler (O'Reilly) — практическое введение в Spring Boot
- **Spring Microservices in Action** — John Carnell, Illary Huaylupo Sánchez (2nd Edition) — Spring Cloud, микросервисы, Service Discovery
- **Cloud Native Java** — Josh Long, Kenny Bastani — Spring Boot и Spring Cloud для облачных приложений
- **Effective Java** — Joshua Bloch (3rd Edition) — фон для тем про SOLID и слоистую архитектуру

### Онлайн-ресурсы

- [Spring Framework Reference](https://docs.spring.io/spring-framework/reference/) — официальная документация ядра Spring (IoC, AOP, транзакции)
- [Spring Boot Reference](https://docs.spring.io/spring-boot/reference/) — официальная документация Spring Boot (автоконфигурация, стартеры)
- [Spring Data JPA Reference](https://docs.spring.io/spring-data/jpa/reference/) — репозитории, derived queries, `@EntityGraph`
- [Spring Security Reference](https://docs.spring.io/spring-security/reference/) — аутентификация, авторизация, JWT
- [Spring AI Reference](https://docs.spring.io/spring-ai/reference/) — `ChatClient`, RAG, Tool Calling
- [Baeldung — Spring](https://www.baeldung.com/spring-tutorial) — практические статьи по всем темам Spring/Spring Boot
- [Spring Guides](https://spring.io/guides) — короткие официальные гайды «Getting Started» по каждой возможности
- [Testcontainers Documentation](https://testcontainers.com/) — интеграционные тесты с реальными зависимостями в Docker
